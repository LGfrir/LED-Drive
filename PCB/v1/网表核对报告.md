## 需要处理的三件事

1. **缺 3V3 / 5V 输出连接器**（J2、J3）。目前 XT60 只作 12V 输入，ESP32-S3 没有取电口。
2. **XT60 是插件（THT）**，与"全部 SMT 贴片"的目标冲突；XT60 也无法贴片。
3. **XT60 极性待确认**：网表里 U1.1=GND、U1.2=+12V。需核对封装焊盘 1/2 与实物红黑线对应关系。若焊盘 1 实际是正极，输入极性就是反的（有 D3 反接保护，不会损坏，但上电不工作）。

## 建议（不影响连接）

网络名全是自动生成的 `$1N2 / $1N4 / $1N5 / $1N7 / $1N8 / $1N9 / $1N11 / $1N15 / $1N16`，
建议改为 `VIN_12V / EN_DIV / SW / BOOT / FB / VIN_F / +3V3 / LED_A`，PCB 布线时好定位。
